## 📌 Project Overview

This project is part of the **Sqrock IT Solution 15-Day Cybersecurity Internship**.

The objective of Day 1 is to understand **Open-Source Intelligence (OSINT)** and **passive reconnaissance** techniques by collecting publicly available information about a practice domain without directly interacting with or attacking the target.

The project implements a Python-based OSINT scanner that collects:

- WHOIS information
- DNS/IP information
- IP geolocation information
- Basic domain intelligence

### 🛠️ Technologies & Tools

- 🐍 Python
- 🐉 Kali Linux
- 🌐 DNS / Socket
- 🔎 WHOIS
- 📡 Requests
- 💻 VirtualBox
- 📝 GitHub

### 🎯 Learning Objectives

- Understand the concept of OSINT
- Differentiate passive reconnaissance from active reconnaissance
- Perform WHOIS information gathering
- Perform DNS and IP resolution
- Retrieve basic IP geolocation information
- Automate reconnaissance tasks using Python
- Document cybersecurity activities professionally

### ⚠️ Ethical Notice

This project is intended strictly for **educational purposes and authorized laboratory environments**. Only domains, systems, and information that I am authorized to examine are used for testing.
